The Tunnel first goal is to make exchange in crypto world easier.
People can send buy or sell orders in an order book.
Every type of crypto can be found and a section other allow the users to give a price even to the ones just created.

<img width="1886" height="822" alt="image" src="https://github.com/user-attachments/assets/9472af81-066e-46ab-85cf-9c8a38ca5a4b" />

The second use of the Tunnel is to make possible the exchange through two chains.
Put in the order the preffered sending chain. Give also the preffered receiving chain. Both can be different.
Users can then chat between each other and create unstandardized exchanges.
